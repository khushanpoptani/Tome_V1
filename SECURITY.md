# Security Policy

Tome is in foundation development and has no supported public release yet.

Please do not open public issues for suspected vulnerabilities. Use the repository's
private security-advisory flow so maintainers can validate and coordinate a fix before
disclosure.

Include:

- the affected revision and platform;
- reproduction steps;
- expected and observed behavior;
- potential impact;
- any suggested mitigation.

Never include real credentials, private source code, model data, or sensitive logs in a
report.
